Экспериментальное сравнение сканеров
Гуцалов Егор Никитич и Лемдянов Илья Данилович, группа 5030102/30201

Отчёт
  report.pdf — готовый доклад для чтения и печати.
  report.tex — основной файл. Текст глав в sections/, таблицы в tables/.
  Для сборки из этого каталога выполнить дважды:
      xelatex -halt-on-error report.tex
  Требуются XeLaTeX, русский модуль babel, шрифты DejaVu, стандартные
  пакеты TeX Live для математики, таблиц и ссылок. Графики уже построены.

Материалы опытов
  В appendix/stand.zip находятся точные исходники использованного стенда:
  сканеры, правила генераторов, CMake, тесты, независимый эталон, генератор
  входов, измеритель, исходный псевдокод и таблица замен.
  В appendix/results/ сохранены 1 344 строки общей серии final_2026-11-28
  для 21 входа, 4 вариантов и 16 раундов. measurements.csv и
  measurements.jsonl содержат одни и те же наблюдения. fields.txt описывает
  поля и единицы. inputs.json содержит рецепты, частоты и хеши входов.
  REPORT.md содержит сводку А и парные отношения Б. В summary.json каждый
  числовой массив имеет порядок [медиана, Q1, Q3], поле branch_wins —
  число раундов, где branch завершил проход раньше.
  Скрипт appendix/figures.py читает исходные CSV и inputs.json, проверяет
  полноту и порядок измерений, строит tables/a.tex, tables/b.tex и оба
  графика, обновляет сводки и JSONL. Требуется Python 3 с matplotlib:
      python appendix/figures.py
  В figures/prefix.drawio хранится редактируемая схема. Для обновления
  figures/prefix.pdf в draw.io выбрать экспорт в PDF с обрезкой по рисунку.

Повторение измерений
  Распаковать appendix/stand.zip в отдельный каталог и перейти в него.
  Установить CMake, компиляторы C и C++, flex и re2c. В Windows использован
  MinGW-w64 (gcc/g++ 13.2.0), win_flex 2.6.4 и re2c 4.6.
  При наличии нескольких компиляторов задать CC и CXX до первого запуска.
      python experiments/a/run_experiment.py --run-id repeat
  При необходимости добавить --flex и --re2c с путями к генераторам.
  Скрипт создаёт experiments/a/results/repeat/ с единым CSV всех четырёх
  вариантов. Для пересчёта графиков по новой серии скопировать measurements.csv,
  REPORT.md и inputs.json из нового запуска в appendix/results/ копии отчёта.
  Команды дополнительных проверок в том же каталоге распакованного стенда:
      cmake --build build/experiment_a --config Release --target experiment_b_checks
      ctest --test-dir build/experiment_a -C Release --output-on-failure
  Для опыта Б отдельный запуск не нужен. Пара образуется внутри раунда
  для одного входа. До обработки следует сохранить переводы строк корпуса:
  в приложенном файле 17 430 байт, его SHA-256 приведён в inputs.json.
