# Опыт Б

Из корня проекта запустите ./build.sh b или python3 experiments/b/run_experiment.py.
Нужны CMake, Python 3.10+ и компиляторы C и C++. Этот режим собирается
без flex и re2c.

Измеряются table и branch на общих для А и Б входах. Сначала
проверяются представления ДКА, затем выдача на каждом входе сверяется
с эталоном. На каждом входе выполняется 16 парных раундов с чередованием
порядка. Отношение table/branch вычисляется внутри каждой пары.

Успешный запуск публикует measurements.csv, fields.txt и REPORT.md в
results/<run_id>/. О лексике и том, что меняется в опыте, см. [comments.md](comments.md).
