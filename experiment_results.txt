ФОРМАТ РЕЗУЛЬТАТОВ ЭКСПЕРИМЕНТОВ А И Б

1. Хранение. Один каталог на сеанс измерений: build/results/<run_id>/.
В нём run.txt (условия), measurements.csv (исходные замеры), summary.csv
(сводка). CSV в UTF-8, первая строка — заголовок, разделитель — запятая,
десятичная точка. Терминал показывает сводку и ошибки. Поток лексем
при необходимости записывается только в отдельном проверочном прогоне.

2. Единица наблюдения. Одна строка measurements.csv — один полный проход
одной реализации по одному непустому файлу, успешно прочитанному до TOK_EOF.
Заголовок:
experiment,input_id,input_sha256,variant,round,order,bytes,tokens,elapsed_ns,checksum

experiment = A или B. В A варианты flex, re2c, table, branch; в B — table, branch.
round — номер раунда от 1, order — очередность внутри раунда на данном входе.
bytes — длина всего файла в байтах, включая пропуски и комментарии.
tokens — число выданных лексем без TOK_EOF. elapsed_ns — целое число
наносекунд от начала первого next до возврата из цикла по TOK_EOF.
В интервал входит одинаковое для всех накопление checksum по тройкам
(вид, начало, конец); алгоритм контрольной суммы общий и указан в run.txt.
open, close, чтение файла, сверка, прогрев, печать и запись CSV — вне интервала.

3. Сводка. Одна строка summary.csv на (experiment,input_id,variant):
experiment,input_id,variant,rounds,bytes,tokens,median_ns_per_byte,q1_ns_per_byte,q3_ns_per_byte

Для каждого прохода x = elapsed_ns / bytes. Выводим медиану x и квартили
Q1, Q3; для воспроизводимости используем линейную интерполяцию в отсортированном
ряду по индексу (n−1)p при p = 0.25, 0.50, 0.75, индексация с нуля.
Для Б дополнительно выводим в терминал по каждому входу медиану и Q1–Q3
парных отношений elapsed_ns(table) / elapsed_ns(branch) внутри одного раунда.
Значение 1.20 означает, что table затратил на 20% больше времени, чем branch.

4. В run.txt записываем дату, версию исходников, CPU, ОС, компиляторы и флаги
оптимизации, версии генераторов, часы, число прогревов и раундов, команду
запуска, параметры генерации входов. Полный хеш входа есть в CSV.
Время измеряем монотонными часами. Наносекунда — единица записи.
Если выдачи или контрольные суммы разошлись, сеанс помечаем прерванным;
причину и позицию выводим отдельно, строку с ошибкой в сводку не включаем.
