# Опыт А

Из корня проекта запустите ./build.sh a или python3 experiments/a/run_experiment.py.
Нужны CMake, Python 3.10+, C/C++-компиляторы, flex и re2c. Пути к
генераторам можно задать параметрами --flex и --re2c у Python-скрипта.
В Windows при новой конфигурации используется MinGW Makefiles.

Измеряются flex (-8 -Cf), re2c и собственный табличный сканер, по 15
раундов. Общие контрольные тесты используют также вариант с ветвлениями.
Каждый измеряемый поток предварительно сверяется с эталоном по видам и
байтовым границам лексем. Для А и Б используется общий генератор входов.

Успешный запуск публикует measurements.csv, fields.txt и REPORT.md в
results/<run_id>/. Интерпретация результатов — в [comments.md](comments.md).
